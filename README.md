# 小红书博主工具生成器 · Xiaohongshu Blogger Tool Generator

一个给**内容创作者**用的 Claude / Codex Skill:把"我有一个具体的内容工作流痛点,但不会写代码"翻译成**可直接拿去 Cursor / Lovable / v0 / 飞书 开做的小工具方案**。

> 不教你学编程,而是把你的痛点翻成"你自己就能开做"的一份结构化方案包。

## 它解决什么

博主/运营/MCN 每天都在手工硬扛一些小事:报价靠脑子算、选题散落在各处、资料没处归、复盘靠感觉。这些都值得有个专属小工具,但"不会写代码 + 说不清需求 + 不知道用哪个工具"卡住了所有人。

这个 Skill 就是那一层翻译器。

## 输入 → 输出

**你给:** 一句话痛点就够(身份、赛道、想做什么,能说多少说多少)。

**你得到:**
1. 三种方案方向(最轻量 / 最实用 / 最适合传播)
2. 选定后的完整落地包:工具定位 → 页面/表结构 → 字段与逻辑 → **Cursor/Lovable/v0/飞书 各版可复制 Prompt** → 1 天 MVP 步骤(含避坑) → **小红书笔记包**(标题/封面/截图/评论引导)

## 怎么用

把本目录作为一个 skill 放进你的 Agent 技能目录即可:

- **Claude Code**:放到 `~/.claude/skills/xiaohongshu-blogger-tool-generator/`
- **Codex / 其他兼容 Agent**:放到对应的 skills 目录

然后直接说出你的痛点,例如:
> "我是美妆博主,接品牌合作报价老靠手算,经常报错价,想做个报价小工具。"

> 如果通过小红书 RedSkill 安装:`复制安装口令 →（发布时补充）`

## 安全与合规

本 Skill 刻意做成**低权限、强结果、可解释**:

- ❌ 不做自动发帖/评论/点赞/私信/养号/批量互动
- ❌ 不索取 Cookie / Token / 账号密码,不抓取平台数据
- ❌ 不替你连接并操作你的账号——只给方案和步骤,你自己掌控
- ✅ 涉及第三方 API/数据库时,只给合规、最小权限、用途透明的建议
- ✅ 提醒你粘贴日志/报错前先脱敏
