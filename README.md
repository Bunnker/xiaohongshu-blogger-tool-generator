# 小红书博主工具生成器 🛠️

**不会写代码,也能给自己的内容工作流做一个专属小工具。**

你用人话说一个痛点,它给你一份**今天就能开做**的工具方案——而不是又一篇"教你学编程"的教程。

---

## 这是什么

做内容最烦的,往往不是写文案,而是那些**每天重复、又只能手工处理**的小事:报价靠脑子算、选题散落在各处、资料东一块西一块、复盘全靠感觉。

这个工具(一个 AI「Skill / 技能包」)就是帮你把这些痛点,**翻译成一个你自己就能做出来的小工具方案**。你只要说出烦恼,它会给你:

- 🎯 **三种方案方向**(最轻量 / 最实用 / 最适合发小红书),像挑笔记一样挑一个
- 🧩 工具长什么样:页面结构、要哪些字段、怎么算
- 📋 **可以直接复制的「指令」**——给 Cursor / Lovable / v0 / 飞书 各备一份
- ⏱️ **一天就能做完**的步骤,连容易踩的坑都帮你标出来
- 📕 顺手帮你写好**小红书笔记**(标题 / 封面文案 / 该截哪些图)

> 一句话:它是你的「产品军师 + 翻译官」,**不替你操作任何账号**,只给你一份能立刻动手的方案。

## ⚠️ 先说清楚(这点最多人误会)

它给你的是**方案 + 可复制的指令**,**不是一个点开就能直接用的成品 App**。完整链路是这样的:

```
你说痛点 → 这个 Skill 给你方案和指令 → 你把指令复制到 AI 编程工具里 → 工具帮你把成品做出来
```

所以你还需要一个「能干活的 AI 编程工具」(下面《怎么用》列了支持哪些,国内国外都有,免费版也够)。

## 适合谁

博主 · 内容运营 · MCN · 知识博主 · 自媒体小团队 —— 任何「有重复的内容杂事、想要个趁手小工具、但不会写代码」的人。

## 举三个例子

- 💄 **美妆博主**:品牌合作**报价计算器**——填几个数自动算总价,再不漏算植入条数
- 🎓 **留学博主**:**选校资料整理器**——把散乱的院校信息归到一处、可对比
- 📚 **知识博主**:**选题日历 + 复盘板**——灵感不再乱飞,哪个选题做过一眼看清

## 怎么用

1. **把这个 Skill 装进你的 AI 编程工具**(见下表)
2. **跟它说你的痛点**,比如:「我是美妆博主,接广告报价老靠手算,想做个报价小工具」

它就会开始给你出方案。

### 支持哪些工具 + 各自装在哪

把整个 `xiaohongshu-blogger-tool-generator` 文件夹(里面有 `SKILL.md`)复制到下表对应目录即可。免安装,放进去就生效(个别工具要重启)。

| 工具 | 厂商 | 把文件夹放到 | 触发方式 |
|---|---|---|---|
| **Claude Code** | Anthropic | `~/.claude/skills/` | 自动识别,或输入 `/xiaohongshu-blogger-tool-generator` |
| **Codex CLI** | OpenAI | `~/.agents/skills/`(老版本 `~/.codex/skills/`) | 自动,或 `$xiaohongshu-blogger-tool-generator` |
| **Trae** | 字节跳动 | `~/.trae/skills/` 或项目内 `.trae/skills/` | 自动;也可在 Trae 里直接上传 `SKILL.md`/zip 导入 |
| **通义灵码 Lingma** | 阿里 | `~/.lingma/skills/` 或 `.lingma/skills/` | `/技能名`(装完**重启 IDE**) |
| **Qoder** | 阿里 | `~/.qoder/skills/` 或 `.qoder/skills/` | `/技能名`;也支持 `npx skills add` |
| **CodeBuddy** | 腾讯 | `~/.codebuddy/skills/` 或 `.codebuddy/skills/` | AI 自动识别调用 |
| **文心快码 Comate** | 百度 | `~/.comate/skills/` 或 `.comate/skills/` | AI 自动识别 |

> 💡 **小技巧**:Trae / 通义灵码 / 文心快码 等还会读取通用标准目录 **`.agents/skills/`**;文心快码甚至能直接读 `.claude/skills/`。所以放进 `.agents/skills/` 往往就能多个工具通用。
>
> 这是一个标准的 **[Agent Skills(`SKILL.md`)](https://agentskills.io) 技能包**(2025 年 12 月发布的开放标准),理论上**任何支持该标准的工具都能用**。上表是已确认支持的(国内主流 AI 编程工具基本都支持了);暂不支持的(如 CodeGeeX)请换用上表里的工具。

也可以直接克隆后把文件夹拷进去:

```bash
git clone https://github.com/Bunnker/xiaohongshu-blogger-tool-generator
```

## 常见问题

**Q:没有 AI 编程工具能用吗?** 不能直接用。先装一个上表里的工具(Claude Code、Trae、通义灵码都行,国内免费版也够),再用这个 Skill。

**Q:能在小红书 App 里直接用吗?** 不能。它是给 AI 编程工具用的技能包;小红书笔记是引导你去这些工具里使用。

**Q:不会部署 / 不会上线?** 方案里会给你「一天就能做完」的步骤;复杂的上线、数据库,它会用最简单的方式带你走,实在不需要的就不让你碰。

**Q:做出来跑不起来 / 报错了?** 把报错原样发回给你正在用的 AI 工具让它修;这个 Skill 的方案里也会提前帮你标出常见的坑。

**Q:它会乱改我的东西 / 要我的账号吗?** 不会。见下方安全说明。

## 安全与合规

本 Skill 刻意做成**低权限、强结果、可解释**,并对齐小红书官方《Skill 上传规范》:

- ❌ 不做自动发帖 / 评论 / 点赞 / 私信 / 养号 / 批量互动
- ❌ 不索取 Cookie / Token / 账号密码,不抓取任何平台数据
- ❌ 不替你连接、操作你的账号——只给方案和步骤,**你自己掌控**
- ✅ 涉及第三方 API / 数据库时,只给合规、最小权限、用途透明的建议
- ✅ 提醒你粘贴日志 / 报错前先脱敏
